## 2. Hard Safety & Architectural Decisions

1. **Kernel-Only Scope Rule:**
   - ZERO changes to Android userspace (`/system`, `/vendor`, `/product`, `/odm`, `init.rc`, PowerHAL, `service.d`).
   - Governor selection, rate limits, and dynamic headroom curves are 100% contained within kernel source (`cpufreq_schedutil.c`) and exposed exclusively via standard kernel sysfs nodes (`/sys/devices/system/cpu/cpufreq/policy*/schedutil/`).
2. **MediaTek DVFS & DSU Preservation:**
   - Fast-switching calls `mtk_cpufreq_hw_fast_switch` via `cpufreq_driver->fast_switch`.
   - Android vendor hook `android_vh_cpufreq_fast_switch` is fired by `cpufreq_driver_fast_switch` in `drivers/cpufreq/cpufreq.c`, maintaining closed vendor DSU/interconnect voting and thermal protection.
3. **Strict Rootless Variant Hygiene:**
   - `hyperos/normal` and `coloros/normal` MUST NEVER contain NoMount, KernelSU, BakaSU, or SUSFS code or configuration fragments.
